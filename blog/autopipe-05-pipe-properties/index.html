AutoPIPE（05）— 管线属性：规格、材料与附属层

2026-11-01AutoPIPE管道属性数据模型

按数据职责整理 Pipe Properties 字段，分析尺寸规格、材料牌号、保温外护、介质和规范参数的来源，以及属性与几何、工况的边界。

Pipe Properties 把一根管道计算所需的规格、材料和附属层参数集中在一起。窗口中的字段有不同的数据来源：有些用于查库，有些是查询结果，还有些由用户补充。

截图中，Pipe Identifier 为 PP_A，公称直径为 20，Schedule 为 STD，材料牌号为 CMN-245。公称尺寸只是规格索引，实际截面计算还要使用查出的外径和壁厚。

标识与尺寸规格

字段含义
Pipe Identifier这组管道属性的标识
Tag No.工程位号
Line Class管道等级标识
Nominal Diameter公称直径，用于选择规格
Schedule壁厚等级，用于选择规格
Actual O.D.实际外径
Wall thickness壁厚
Corrosion Allow腐蚀裕量
Fab. thickness制造壁厚公差相关输入

选择公称直径和 Schedule 后，软件可以从 Component 库取得外径与壁厚。腐蚀裕量和制造公差在相关计算中修正可用厚度；它们的输入单位、定义和应用方式要结合当前规范确认。

研发时需要区分三个值：规格查询键、查库得到的名义数据，以及规范计算使用的有效参数。例如，不能把扣除腐蚀裕量后的厚度直接覆盖原始规格壁厚，否则后续更换规范或重新编辑时会丢失来源。

保温、外护、内衬与介质

类别窗口字段数据用途
保温层Insul thickness / material / density记录保温厚度、材料及密度
外护层Clad thickness / material / density记录外护厚度、材料及密度
内衬Lining thickness / density记录内衬厚度与密度
管内介质Specific gravity of contents记录介质比重

这些数据参与相关重量和截面尺寸计算。例如，保温层增加单位长度重量，在海洋环境中，外部尺寸还可能用于相关环境载荷计算，具体取值由相应功能设置决定。

Specific gravity 是比重，为无量纲量，应与以 kg/m³ 表示的密度分开记录。界面上相邻的数值框，也可能具有完全不同的量纲。

材料牌号与材料性能

类别窗口字段含义
材料选择Pipe Material具体材料牌号，如 CMN-245
材料类别Composition牌号关联的类别，如 CS
弹性参数Long / Hoop / Shear modulus纵向、环向和剪切模量
物性Density / Poisson’s ratio密度、泊松比
强度Minimum yield / Minimum tensile最小屈服强度、最小抗拉强度

牌号和类别对应上一篇的 SPEC → MATL 关系。对于当前文件中的 CMN-245，SPEC 提供 245 MPa 的屈服强度基值和 415 MPa 的抗拉强度基值，CS 提供密度、泊松比及温度曲线。

窗口中的数值按当前单位配置显示。截图没有给每个字段单独标注单位，阅读模量或密度数值时，应先确认单位设置。Bentley 的界面说明指出，当前字段的单位显示在主窗口右下角；不能把源库中的 GPa 数值与窗口数值直接比较。

温压工况窗口还会按运行温度取得 Hot modulus 和强度降额。因此，管线属性中的材料基值、材料曲线和每组工况采用的温度相关值，需要在数据模型中保留各自含义。

制造、焊接和疲劳参数

字段含义
Long weld fac ZL纵向焊缝相关系数
Circ weld fac ZC环向焊缝相关系数
Fab. factor制造系数
Ovality Oo初始椭圆度
Fatigue Curve疲劳曲线
Environmental Factor环境修正系数

这些字段的可用性及解释与规范有关。实现属性面板时，不能仅凭字段名称就把它们作为对所有规范通用的一套参数。

Suppress low temp warnings 则是提示控制选项，用于抑制低温警告。它的语义应与材料性能数值分开，勾选该项并不等于修改了材料的低温性能。

属性、几何和工况分别组织

这张窗口没有定义管段长度、走向，也没有列出每组温压数据。可以据此划分三类职责：

数据负责的内容
几何与连接管道在哪里、走向如何、连接到哪里
管线属性使用什么尺寸、材料和附属层
工况数据某个状态下，各位置的温度、压力及相关参数

后面的数据结构方案会让组件通过 PipePropertyId 引用管道属性，再单独组织端口、连接和载荷。这样，同一规格可以在多段几何中使用；一段几何也可以关联多组工况数据。这里是面向研发的设计划分，不据此断定 AutoPIPE 内部采用相同的对象结构。
