AutoPIPE（01）— 模型设置：单位配置与竖直方向

2026-11-01AutoPIPE单位系统模型配置

从 General Model Options 入手，梳理 AutoPIPE 的输入输出单位、UNT 配置文件、内部基准单位和全局竖直方向。

AutoPIPE 新建模型时，先在 General Model Options 中确定规范、单位、坐标方向、温压工况组数和基础库。这些设置决定后续输入数据的解释方式。

这组笔记从软件研发的角度整理 AutoPIPE：先看配置和库文件如何提供数据，再看管道、支撑、载荷如何组成模型。界面行为和库文件内容可以直接观察；后面涉及的 C++ 数据结构则是据此提出的建模方案。

全局设置分别管什么

设置负责的内容
Piping Code / Edition规范体系与版本，决定校核规则
Units file name — Input / Output输入界面与结果输出采用的单位配置
Vertical axis direction全局坐标系中代表竖直方向的轴
Number of thermal/pressure cases模型可定义的温度、压力数据组数
Ambient temperature热膨胀计算使用的参考温度
Libraries — Component / Material组件规格库与材料性能库

图中的 DNV Offshore / 2021、AUTOPIPE 和 DNVM2021 分别选择规范版本、组件库和材料库。三者各有职责，不能只凭库文件名判断启用了哪些校核规则。

Input 和 Output 独立选择单位

SI 是 International System of Units，即国际单位制。在这个窗口中，它首先是一个单位配置名称，对应 SI.UNT 文件。

配置用途
AUTOPIPE.UNT基准单位文件，供其他配置参照
SI.UNTSI 单位配置
ENGLISH.UNT英制单位配置
METRIC.UNT另一套公制配置
自定义 .UNT按项目需要调整各类参数的单位

模型分别指定输入和输出使用的配置。例如，Input = SI、Output = ENGLISH，表示按 SI 配置输入和显示模型参数，按英制配置生成相关报告。可选文件及具体输出行为要以安装版本为准。

一套配置也不等于“所有长度都用同一个单位”。坐标、管径、壁厚和位移在配置中有各自的条目，能够分别指定单位。

UNT 按参数类别记录换算关系

.UNT 是有固定列格式要求的文本文件，条目包括参数类别、单位名称以及相对于基准单位的换算系数；温度换算还涉及偏移量。

例如，位移的基准单位为英寸，SI 配置中的位移单位为毫米，对应关系是：

dmm=25.4 dind_{\mathrm{mm}} = 25.4\,d_{\mathrm{in}}dmm​=25.4din​

不能把同一个系数用于所有长度数据。坐标和位移虽然都属于长度量，内部基准单位仍可能不同。后面的 DNVM2021.src 就分别为坐标和尺寸列出了 304.8、25.4 两个系数。

Bentley 的说明指出，AutoPIPE 模型数据库内部使用英制单位。选择 SI 后，界面与报告按所选配置换算数值。这里说的是模型数据库的单位约定，不能据此推断求解器每个中间量的存储方式。

除了数值，字段还必须带有明确的量纲和用途。只保存一个浮点数，再由控件临时猜测单位，会给输入、报告和数据交换留下歧义。

竖直轴赋予坐标物理含义

截图选择 Y-axis，表示正 Y 向上、负 Y 向下，X–Z 平面为水平面。这会影响重力方向、海面高程、浮力和竖向支撑响应的解释。

场景Y 轴竖直时的含义
重力与浮力重力沿 −Y，浮力沿 +Y
海面与海床用 Y 坐标表示高程
浸水范围由管道位置与水面高程判断
位移结果Dy 表示全局竖直位移
支撑竖向约束、间隙及脱离按该方向理解

例如海面为 Y = 0，某节点为 Y = −100 m，则该节点位于海面以下 100 m。如果原点设在海床，海面也可以采用正高程。模型坐标、海面位置与载荷设置需要遵守同一约定。

选定竖直轴后，水深、浮力和海床支撑仍需要各自的数据。竖直轴只定义方向，不能代替环境和边界条件。
