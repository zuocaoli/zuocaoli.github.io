01 · 用 OCCT 将矩形面拉伸成实体

2025-11-09OCCTC++实体建模

从矩形角点构造闭合线框和拓扑面，再沿指定向量拉伸得到实体。

定义矩形的四个角点

gp_Pnt 表示三维笛卡尔坐标系里的一个几何点，gp_Pnt(x, y, z) 用三个坐标指定位置。

从角点构造闭合线框

BRepBuilderAPI_MakePolygon 在这些位置创建拓扑顶点 TopoDS_Vertex，由连接顶点的边组成线框 TopoDS_Wire。

默认构造的 BRepBuilderAPI_MakePolygon 起初为空。沿矩形周边的顺序调用 Add(const gp_Pnt&)，第一次记录起点，后续调用用直线边连接当前末端和新顶点。加完四个角点后，Close() 把最后一个顶点连回第一个顶点，补上第四条边。

对这个构造器，IsDone() 表示已经建成至少一条边。构造成功后，outline.Wire() 返回已经建好的整条线框，类型是 const TopoDS_Wire&。

用闭合线框限定矩形面

BRepBuilderAPI_MakeFace 是拓扑面的构造器。带边界的 TopoDS_Face 由底层几何曲面和边界线框共同定义。曲面决定面的几何形状，线框限定它在曲面上覆盖的区域。

BRepBuilderAPI_MakeFace 接收 outline.Wire() 返回的线框。四条边共面，构造器可以据此确定底层平面，并用线框围出矩形区域。base.IsDone() 检查面是否建成，随后 base.Face() 返回结果，类型是 const TopoDS_Face&。

这一步决定了拉伸的结果类型。用这个闭合线框做直线扫掠，可以得到由侧面组成的壳。把线框先构造成面，再扫掠整个面，底面、顶面和侧面就能围出一个实体。

用向量指定方向和距离

gp_Vec 表示三维向量，构造函数的三个实参是 X、Y、Z 分量。示例中的 gp_Vec(0, 0, 20) 表示沿正 Z 轴移动 20 个长度单位。

BRepPrimAPI_MakePrism 是直线拉伸构造器。做有限拉伸时，构造器接收一个起始形状和一个位移向量。矩形面的位置确定起点，向量确定方向和距离。面从 z = 0 出发，顶面就落在 z = 20。prism.IsDone() 检查拉伸是否完成。

读取拉伸结果与错误消息

拉伸完成后，prism.Shape() 以 const TopoDS_Shape& 返回结果。TopoDS_Shape 是通用拓扑类型，可以表示顶点、边、线框、面、实体以及复合形状。

IsNull() 为 true 表示结果没有关联的拓扑形状。取得非空结果后，程序输出 Extrusion completed。如果任一步构造抛出 Standard_Failure，程序捕获这个 OCCT 异常基类，并用 what() 输出错误消息。
