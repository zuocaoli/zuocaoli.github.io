AutoPIPE（02）— 管道规范：版本、材料数据与校核规则

2026-11-01AutoPIPE管道规范DNV

区分 Piping Code、Edition 和材料库，介绍常见管道规范与 DNV Offshore 的校核范围，以及规则代码和库数据之间的边界。

Piping Code 指定管道采用哪套计算与校核规则，Edition 指定规则版本。材料库则提供计算所需的性能和强度数据。模型同时选择这几项，是因为规则和数据需要配套。

按管道用途认识规范

常见的 ASME 管道规范覆盖不同用途：

规范主要用途典型场景
ASME B31.1动力管道电厂蒸汽、给水
ASME B31.3工艺管道炼油、化工、制药装置
ASME B31.4液体与浆体输送管道原油、成品油输送
ASME B31.8燃气输送与配气管道天然气输送、配气系统
ASME B31.12氢气管道工厂氢气管道、输氢管线

此外还有区域性或特定行业规范：

规范主要用途
EN 13480欧洲金属工业管道
DNV-ST-F101海底管道系统
CSA Z662加拿大油气管道系统
ASME BPVC Section III（NB、NC、ND）核设施相应等级的部件及管道
RCC-M法国压水堆核岛机械设备设计与建造，包含相关管道要求

国内工程还会涉及 GB/T 20801 系列《压力管道规范 工业管道》、GB 50316《工业金属管道设计规范》等。实际采用的规范及版本由项目设计依据确定；软件是否支持对应版本，需要查其版本说明，不能由这张分类表推断。

DNV Offshore 处理哪些问题

本组笔记的模型选择 DNV Offshore / 2021，对应 DNV-ST-F101《海底管道系统》的规范体系。旧资料和库文件标题中还可能出现 DNV-OS-F101、DNVGL-ST-F101 等历史名称。

海底管道同时受内压、外部海水压力、轴向力和弯矩作用，需要检查不同失效模式：

校核类别关注的问题
内压承载能力（Burst）管壁能否承受内部压力
外压塌陷（Collapse）外压作用下截面是否失稳
传播屈曲（Propagation Buckling）局部塌陷是否沿管道扩展
组合载荷下局部屈曲（Combined Loading）压力、轴向力和弯矩共同作用下的局部承载能力

这套规范采用极限状态设计方法，按失效模式比较载荷效应和承载能力，并通过安全等级、分项系数等考虑后果与不确定性。上表用于说明规范内容，具体计算式、适用条件和软件覆盖范围仍需查对应版本的帮助文档。

DNV-ST-F101 还包括材料、制造、安装和运行等要求。模型中的校核结果只覆盖软件实施的分析与检查项目。

规则代码与库文件各自负责什么

AutoPIPE 的规范算法内置在程序中。Bentley 明确说明，不能通过复制或编辑库文件新增一套规范；新增规范或更新算法需要使用支持它的软件版本。

内容在本例中的来源
管道及管件规格AUTOPIPE.src 编译得到的组件库
材料物性、强度与温度降额DNVM2021.src 编译得到的材料库
校核公式、适用条件和判断逻辑程序内置的规范实现

因此，DNVM2021 提供 DNV 配套材料数据，完整的 DNV 校核逻辑由程序执行。组件库中的外径、壁厚和材料库中的强度参与计算，规范规定如何使用这些数据评价结果。

这也解释了为什么选中一个材料库后，还需要单独选择 Piping Code 和 Edition。库的文件名、内部标题和界面规范名称可能保留不同年代的命名，识别兼容关系应依据软件说明。

对研发而言，这里形成了清楚的维护边界：规格和材料数值可以通过库维护；规则版本的变更还涉及算法、参数及结果解释。只更新一份材料表，不能视为完成了规范升级。
