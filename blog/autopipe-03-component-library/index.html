AutoPIPE（03）— 组件库：从 SRC 到 LIB

2026-11-01AutoPIPE组件库文件格式

梳理 AutoPIPE 组件库与材料库的职责、SRC 到 LIB 的转换流程，并以 AUTOPIPE.src 为例分析七张数据表及其固定格式。

General Model Options 中的 Libraries 分成 Component 和 Material 两项。前者提供尺寸规格，后者提供材料性能。选中组件库后，还要在建模时继续选择公称直径、Schedule、阀门类型等，才能取得具体规格的数据。

两类库的职责

库典型数据使用位置
Component外径、壁厚、阀门尺寸和重量、保温及外护材料等管道与管件属性输入
Material密度、泊松比、弹性模量、热膨胀、强度及规范相关材料数据刚度、自重、热变形和校核计算

例如，在组件库中按“公称直径 + Schedule”查询，可以得到实际外径和壁厚；选择材料牌号后，再从材料库取得物性和强度数据。两类库独立选择，但材料库需要与模型采用的规范及版本匹配。

SRC 是源数据，LIB 供程序加载

AutoPIPE 的这两类库采用专用文件：

.SRC 是按固定格式组织的 ASCII 文本，可以查看和维护；.LIB 是转换后供软件读取的数据文件。这里的 .LIB 是工程数据资源，与 C/C++ 链接库没有关系。

Bentley 要求修改 .SRC 后重新生成 .LIB。从文件用途看，这个阶段把可编辑的表定义和记录转换为程序使用的专用格式，可以减少加载时的文本解释工作，也能提前发现部分格式问题。它不能保证录入的工程数值正确。

公开资料没有给出 .LIB 的完整二进制布局。不能仅凭“编译”二字就断定其中使用了哪种索引或压缩算法。AutoPIPE 其他模块还可能使用 .mdb 等文件，它们与这里的库格式应分别讨论。

库的位置随版本变化。可以先在 Tools → Settings → Preferences 中查看 Program Data Path。例如某些版本的 .LIB 位于 C:\ProgramData\Bentley\AutoPIPE 2025\，源文件在其 Libraries 子目录；另一些版本把源文件放在安装目录中。

AUTOPIPE.src 的七张表

本组笔记保存的 AUTOPIPE.src 以 07 开头，后面共有七张表：

表标识内容
PIPE公称直径、实际外径、Schedule 和壁厚
INSL保温材料与密度
CLAD保温外护材料与密度
VLV1阀门类型、规格、重量和长度等
FLTP标准法兰数据
FLNB大直径 B 系列法兰数据
FLD1流体体积模量和比重

这些是当前文件的内容，不代表每个组件库都收录相同的表和记录。

表定义与记录分开

每张表先描述如何读取数据，再列出实际记录。以 PIPE 表为例，格式定义中可以看到：

A、F 等格式记号描述字符和数值字段的读取方式，字段定义还引用单位编号。这类文件依赖列位置和格式宽度，不能按普通的空格分隔表格处理。

下面是紧接着的部分规格记录，保留原始缩进：

这一组记录对应公称尺寸 0.125、实际外径 0.405，后面分别列出 STD、10S、40 等 Schedule 及其壁厚。例如 STD 对应 0.068。

这些尺寸采用源库的英寸单位，不能因为模型界面选择 SI，就直接把 0.405 当成毫米。当前 AUTOPIPE.src 没有显式 UNITS 区段，读取时还需要遵守该格式规定的基准单位；下一篇材料库则带有自己的单位定义。

从数据组织看，查询链是“库 → 表 → 规格记录 → 字段值”。界面的下拉选择沿这条链定位数据，随后再按模型单位显示。
