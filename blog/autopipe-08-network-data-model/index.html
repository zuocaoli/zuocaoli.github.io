AutoPIPE（08）— 管道网络：组件、几何点与连接端口

2026-11-01AutoPIPEC++数据结构网络拓扑

给出一种面向管道建模的 C++ 数据结构方案，分开表达组件、几何点、连接端口和连接记录，并说明网络索引及一致性约束。

管道网络可以分支、形成闭环，也可能暂时包含多个不连通部分，适合用图表达。这篇给出一种用于前处理建模的 C++ 设计方案，依据前面观察到的对象关系展开，不代表 AutoPIPE 的内部实现。

以下代码关注数据关系，省略向量、具体属性、强类型 ID 及哈希函数的实现。ComponentId、PointId、PortId 等分别表示不同类别的稳定标识。

管径、材料、保温等通过 PipePropertyId 引用属性记录，几何和连接由另外的数据表达。

几何点有用途，端口声明连接位置

同一个组件中，不同点承担不同职责。可以用角色标识端点、三通支点和弯头控制点：

Port::pointId 引用所属组件内的几何点，outwardDirection 记录从组件内部指向外部的方向。坐标和方向采用统一的坐标约定。

几何点能够用于定位、几何构造或附着位置；端口则明确声明一个对外连接接口。不是每个几何点都需要端口：

查询相邻对象与维护约束

给定一个 PortRef，先从 connectionByPort 查连接 ID，再取得 Connection，比较其两端引用，取另一端就得到相邻端口。最后用该端口的 componentId 查组件。索引中不存在该端口时，它是未连接端口。

三通分别查询三个端口，就能取得最多三个相邻组件。遍历整个网络时还需要访问标记，以处理闭环和多个不连通部分。

建立、删除连接时，至少维护以下约束：

约束检查内容
引用有效组件和端口都存在，端口属于所引用的组件
端口可用普通端口尚未被其他连接占用，且不是与自身连接
连接不重复A↔B 与 B↔A 视为同一连接
几何及规格匹配按建模规则检查位置、方向、口径等
索引一致两端索引与主连接记录一起更新
