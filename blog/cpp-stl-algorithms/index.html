泛型算法

C++标准库提供了一些泛型算法，使用时需要包含对应的头文件：

1. 为什么引入泛型算法而不是使用方法？
  一方面，内建的类型是不支持方法的，如int、char、数组、指针等，这些类型不支持方法，只能使用运算符。另一方面，一些方法的计算逻辑是相似的，没有必要重复定义。

3. 迭代器与泛型算法？
  迭代器是算法与数据结构之间的桥梁，泛型算法使用迭代器访问元素。

4. 泛型算法与类方法名称相同时？
  此时使用类方法，因为，为了实现“泛型”带来了性能损失，例如： std::find和std::map::find，std::find是线性查找，而std::map::find是二分查找。

典型泛型算法

读算法

  给定迭代区间，读取其中的元素并进行计算： accumulate/find/count。

accumulate

  对元素进行累加计算，需要包含头文件#include <numeric>，函数声明如下：

  • first, last: 输入区间的起始迭代器，[first, last)。
  • init:  进行累加的初始值。
  • op:  二元操作函数对象。它定义了如何将当前累积结果 (result) 与序列中的当前元素 (*first) 组合成新的累积结果。
      如果字符串类型使用accumulate，那就是拼接字符串。

find

  包含头文件#include <algorithm>，函数声明如下：

  • first, last: 输入区间的迭代器，[first, last) 。
  • value: 要查找的值。
  • 返回值： 返回一个迭代器，指向第一个等于value的元素，如果没有元素等于value，则返回last。

count

  包含头文件#include <algorithm>，函数声明如下：

  • first、last:  输入迭代器范围，在输入迭代器范围 [first, last) 中查找满足条件的元素的数量。
    • value:  统计范围 [first, last) 内等于 value 的元素数量。
    • p:  一元谓词，用于判断元素是否满足条件（true：满足条件，false：不满足条件）。
  • 关于UnaryPred（一元谓词）： 一个接受单个参数并返回布尔值的可调用对象，可以是Lambda、函数指针、函数对象。
  • 返回值： typename std::iterator_traits::difference_type，其中typename告诉编译器这是类型而不是值，difference_type：表示两个迭代器间距离的有符号整数类型。

并行计算

  函数声明中的参数为涉及到 ExecutionPolicy 类型用于指定算法执行策略的类型，它允许开发者控制算法是顺序执行还是并行执行。通过传递不同的策略对象，可以控制算法的执行模式（如顺序、并行或向量化），这在处理大规模数据时可以显著提升性能。

  C++ 标准定义了多种执行策略，每种都有对应的全局对象：

策略类型全局对象版本描述
std::execution::sequenced_policystd::execution::seqC++17顺序执行（无并行）
std::execution::parallel_policystd::execution::parC++17并行执行（多线程）
std::execution::parallel_unsequenced_policystd::execution::par_unseqC++17并行+向量化执行（多线程+SIMD）
std::execution::unsequenced_policystd::execution::unseqC++20向量化执行（单线程 SIMD）

  食用方法：

  不同的计算任务对于这几个策略的效率不同，例如排序算法，多线程比单线程有较大提升，但是使用SIMD就没有什么提升了。   Single Instruction, Multiple Data（单指令多数据流），现代CPU具有多PU单元，可以同时计算多条数据流，适用于向量、矩阵运算。

谓词

谓词，一种可调用对象：

  • 返回bool类型的函数对象。
  • 函数接受一个参数，称为一元谓词。
  • 函数接受两个参数，称为二元谓词。
  • 一般使用lambda表达式来定义谓词。
