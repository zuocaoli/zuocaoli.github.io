sar -r命令与sar -S命令

2024-06-17Linux内核

动态显示内存使用情况

sar -r命令

interval：指定采样间隔。
count：指定采样次数。

例如：

  • kbmemfree： 对应于free命令的free。
  • kbavail： 对应 free 中的 available 字段。
  • kbmemused： 对应 free 中的 used 字段。
  • %memused： kbmemused字段所占百分比。
  • kbbuffers+kbcached: 对应free命令输出的buff/cache字段。

sar -S

参数选项： -S 显示swap空间使用情况。
