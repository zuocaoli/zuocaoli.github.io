ParaView（01）— 后处理：输入数据、文件格式与数据内容

2026-11-03ParaViewCAE后处理VTK数据格式

梳理 ParaView 后处理所需的网格、物理量与时间信息，区分 Point Data、Cell Data 和 Field Data，并介绍常见结果文件格式及悬臂梁分析示例。

CAE 的典型流程是：前处理（建立计算模型）→ 求解（计算物理响应）→ 后处理（查看、分析计算结果）。

ParaView 作为后处理平台，接收的通常是求解器输出的数值结果数据。对于常见的有限元、有限体积分析，可以把它理解为：

计算网格 + 附着在网格上的物理量 + 时间或工况信息。

例如，结构求解器输出“每个节点移动了多少、每个单元的应力是多少”；流体求解器输出“各处的压力、速度、温度是多少”。ParaView 根据这些数据生成云图、变形图、流线和动画。

1. 数据中包含什么信息

信息具体内容在后处理中的用途
几何位置节点的坐标，例如 (x, y, z)确定模型在空间中的形状和位置
网格拓扑单元类型，以及每个单元连接哪些节点构成三角形、四面体、六面体等网格
物理量位移、应力、压力、速度、温度等数值数组着色、绘制箭头、计算派生量
时间／工况时间值、载荷步、模态编号等，取决于格式和导出方式切换结果、播放动画、分析变化
分区与集合零件、材料区域、边界面、节点集、单元集单独显示和分析指定区域
辅助信息原始节点／单元 ID、单位、坐标系说明等，是否包含取决于导出方式追踪结果来源和正确解释数值

其中，节点坐标和单元连接关系共同定义网格。例如，一个四面体单元可以由节点 0、1、2、3 组成；只有坐标，没有连接关系，就无法完整表达这个体单元。

规则网格也可以用原点、间距和尺寸等信息隐式定义，无须逐个记录全部节点坐标。

2. 物理量放在哪里：Point Data 与 Cell Data

这是理解 ParaView 数据最重要的区别。

数据位置含义常见例子
Point Data（点数据）每个网格点对应一组数值有限元节点位移、节点温度
Cell Data（单元数据）每个网格单元对应一组数值有限体积单元压力、单元应力结果、材料编号
Field Data（字段数据）不与每个点或单元一一对应的数组整体参数、说明信息等

物理量本身又可以是：

  • 标量：温度、压力，每个位置一个数。
  • 向量：位移、速度，三维情况下通常有三个分量。
  • 张量或多个分量数组：应力、应变；需要明确分量顺序和坐标系。

ParaView 可以把单元数据转换成点数据，便于插值和显示。但转换通常涉及平均或插值，可能改变局部峰值和区域交界处的表现。

有限元中的应力还可能原本位于积分点（高斯点）。导出时需要明确保留积分点数据，还是先外推、平均到节点或单元；这会影响后处理中看到的结果。

3. 常见文件格式

ParaView 通过相应的 Reader（读取器）识别不同格式，再转换成内部的 VTK 数据对象。

格式常见扩展名／入口典型内容和用途
VTK Legacy.vtk网格及物理量，较早的通用格式
VTK XML 非结构网格.vtu四面体、六面体等网格及点／单元数据，适合很多 FEM、CFD 结果
VTK XML 其他网格.vtp、.vti、.vts、.vtr表面网格、规则体数据、结构网格等
VTK 并行／组合／时序入口.pvtu、.vtm、.pvd、.series 等引用分区文件、多个数据块或多个时间步
VTKHDF.vtkhdf按 VTKHDF 规范组织的 HDF5 数据
Exodus II.e、.exo、.ex2 等有限元网格、结果变量、集合和时间步
EnSight.case，以及引用的数据文件几何、物理量和时间序列
CGNS.cgns常见于 CFD，包含网格、分区及流场等
OpenFOAM通常通过 .foam 入口打开算例目录网格、边界区域及各时间目录中的场数据
XDMF.xdmf、.xmf，常配合 HDF5描述网格、属性及其实际存储位置

有些格式把全部信息放在一个文件里，有些采用“入口文件 + 网格文件 + 结果文件”的组合。例如 .pvtu 通常引用多个 .vtu 分区文件，不能只复制入口文件。

具体可用读取器取决于 ParaView 的版本、构建选项和插件。HDF5 是存储容器，自定义 .h5 文件需要配套的数据组织规范或读取器。

4. 以悬臂梁计算结果为例

求解器导出的结果可以包含：

  • 梁的节点坐标，以及四面体或六面体单元。
  • 每个节点的位移 Displacement。
  • 每个单元或节点的应力分量，以及可选的 VonMises 等效应力。
  • 每个载荷步对应的结果。
  • 固定端、加载端和不同材料区域的集合标识。

在 ParaView 中就可以：

  • 选择 VonMises 着色，查看应力分布。
  • 用 Warp By Vector 根据位移显示变形。
  • 沿一条线提取应力或位移曲线。
  • 按载荷步播放变形动画。

这里有两个解释数据时需要核实的细节：

  1. 单位和坐标系需要由文件元数据或导出约定明确，ParaView 通常不能仅凭数值推断。
  2. 如果读取器已经把位移应用到坐标上，再做一次变形会重复叠加。

5. 对应源码

  • vtkDataSet.h：明确定义了“几何、拓扑和属性数据”的模型。
  • VTK XML 读取器配置：展示了文件如何暴露点数据、单元数据和时间步，供 ParaView 后续分析使用。
